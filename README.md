## 編集内容

1. **p.2 展示立面図**: 暖簾を収めるアクリルケースを描画(`add_case.py`)
   - 寸法は作品サイズ欄の「210 × 200 × 100」(高さ×幅×奥行き, cm)= 高2100 × 幅2000 × 奥行1000mm と読んだ
   - 床の線に乗せ、暖簾の中心に左右を合わせて配置(位置は私の仮定)
   - ケースと干渉する寸法線を移動: 2050 は左外(数字は縦書き)、440 は右外、1660 は2pt上
   - ケース内の下部に「アクリルケース(検討中)/高2100×幅2000×奥行1000mm」の注記
2. **p.1 断面図**: 「リードスイッチ+外付け磁石(缶の外からON/OFF)」を削除(`remove_reed.py`)
   - 図のリードスイッチ・磁石・点線・⑤マーカーを削除、凡例⑤を削除して詰め、旧⑥→⑤・旧⑦→⑥に振り直し

## 再実行の手順(元PDFが更新されたとき)

```
python3 add_case.py      # 元PDF → アクリルケース版を作り直す(p.2)
python3 remove_reed.py   # アクリルケース版に p.1 の削除を適用(必ず add_case.py の後)
```

- 要: Python 3 と PyMuPDF(`import fitz`)。
- スクリプトはコンテンツストリームの文字列を厳密に探すため、元PDFの該当箇所が変わっていると `AssertionError` で止まる。止まったら元PDFの該当部分を読み直して直す。
- 元PDFはExcel書き出しなので、書き出し直すたびにフォント名(`/C0_1` など)が入れ替わる。`add_case.py` は毎回調べ直すので対応済み。

## 確認済みの検証方法

編集後に元PDFと200dpiでレンダリングして画素比較し、(1) 想定した範囲の外に差分がないこと、(2) 文字の増減が意図どおりであること、を確かめている。
